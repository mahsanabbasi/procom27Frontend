# Why Attend fonts

Inter (400–800 variable) and Pixelify Sans (400–700 variable) Latin WOFF2 subsets are self-hosted from the official Google Fonts stylesheet for the supplied HTML reference. Existing Press Start 2P remains shared with the site.

Source stylesheet: https://fonts.googleapis.com/css2?family=Inter:wght@400..800&family=Pixelify+Sans:wght@400..700&display=swap

Original family licenses from google/fonts are included as inter-OFL.txt and pixelifysans-OFL.txt. These fonts load only with the lazy Why Attend stylesheet; no third-party font request is required by the React page.
