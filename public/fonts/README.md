# Existing PROCOM font families, self-hosted

The files preserve the existing Press Start 2P 400 and Space Grotesk 400-700 variable faces, including all subsets supplied by the current Google stylesheet. Source CSS:
https://fonts.googleapis.com/css2?family=Press+Start+2P&family=Space+Grotesk:wght@400..700&display=swap

Press Start 2P source assets: https://fonts.gstatic.com/s/pressstart2p/v16/
Space Grotesk source assets: https://fonts.gstatic.com/s/spacegrotesk/v22/
Licenses are copied from the official google/fonts repository's ofl/pressstart2p/OFL.txt and ofl/spacegrotesk/OFL.txt and included alongside the files. Only Latin subsets are preloaded. The stylesheet records every original unicode-range. No font design or family changes were made.
